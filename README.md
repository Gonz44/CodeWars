# Rosco de Pasapalabra por cursos (3º a 6º de Primaria)

Material listo para usar en clase, con dificultad progresiva según el curso.

## Reglas rápidas
- Cada equipo responde por turnos.
- Si no sabe una respuesta, dice **"pasapalabra"**.
- Al terminar la ronda, se vuelven a leer las letras pendientes.
- Gana quien acierte más.

## Cómo visualizarlo (rápido)

Tienes 3 formas sencillas:

1. **En GitHub**: abre este `README.md` y lo verás ya formateado en tablas.
2. **En VS Code**:
   - Abre la carpeta del proyecto.
   - Abre `README.md`.
   - Pulsa `Ctrl + Shift + V` (o `Cmd + Shift + V` en Mac) para previsualizar Markdown.
3. **En navegador local (sin instalar nada raro)**:
   - Crea un archivo `index.html`.
   - Copia y pega el código de abajo.
   - Ábrelo con doble clic en tu navegador.

## Sugerencia práctica
Si quieres un rosco **100% clásico y limpio**, usa esta estructura:
- 21 letras fijas (incluyendo la **Ñ**).
- 21 pistas breves.
- 21 respuestas únicas.
- Marca algunas como **"contiene la letra"** cuando no haya término fácil que empiece por esa letra.

Si quieres, en el siguiente paso te lo puedo convertir en una **ficha imprimible (PDF)** y también en una **versión de diapositivas** para proyectar en clase.
